辩证一：剑桥“瑞士中立赋能” ☯ 硅谷“整芯直接下场” CO-OPETITION

过去 35 年，Arm 靠“绝不造芯片抢客户生意”赢得全行业信任；如今推出 Arm AGI CPU，本质是在客户自研能力未及的通用超算 CPU 缝隙中精准补位（携手无意对外卖芯片的 Meta 共研），既捕获单颗数千美元价值，又避免正面冲击苹果、英伟达核心差异化领地。

辩证二：学院派 20 年慢架构验证 ☯ 年度 CSS 敏捷交付 CADENCE

底层指令集（Armv9）保持英国皇家工程院式的审慎长周期演进，绝不轻易试错；但上层垂直事业部（Lumex / Neoverse / Zena CSS）按年度硅谷节奏快速迭代预集成蓝图，做到“地基二十年不动摇，楼层每年换新装”。

辩证三：软银 ~87% 大股东长线意志 ☯ 纳斯达克季度财务纪律 GOVERNANCE

铁律 01 · 单一 ISA 宪法零分支

无论大客户定制还是自研 AGI 芯片，所有二进制指令集必须 100% 统一归口首席架构师委员会审批。

铁律 02 · >80% 极端工程师纯度

严禁行政官僚膨胀稀释剑桥与奥斯汀研发密度（FY26 为 84.1%，8,058 名工程师）。

铁律 03 · 零晶圆重资产免疫

坚持纯无晶圆（Fabless/IP）轻资产边界，借助台积电 N3P/2nm 保持顶级制造力而零产线折旧包袱。

铁律 04 · 前沿 IP 同步平等开放

最新一代 Neoverse 与 Cortex 微架构必须同步向 ATA 外部授权伙伴开放，绝不因自研芯片截留核心 IP。

铁律 05 · 3,000万+ 开发者优先

硬件未至软件先行：通过开源 KleidiAI 让全球主流 AI 模型首日零代码改动跑通端云 Arm 处理器。

铁律 06 · 剥离低效聚焦子系统

持续清理低毛利非核心业务（如剥离 Artisan 物理 IP），全员聚焦翻倍费率的 CSS 与高价值算力平台。
